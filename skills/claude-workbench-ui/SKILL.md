# 操作 Claude 工作台界面

## 前提

先确认在 Claude 工作台里：`echo "$CWB_PORT"` 有输出才能用。没有输出就不要用这个技能，命令也会直接报错退出。

## 命令

脚本用绝对路径调用，不需要改 PATH：

```bash
python3 ~/claude-workbench/bin/cwb.py open <路径> [--line N]
python3 ~/claude-workbench/bin/cwb.py web <网址>
python3 ~/claude-workbench/bin/cwb.py shot <网址> [--out 路径] [--size 1280x800]
```

- `open`：在右栏“预览”里打开文件或文件夹，`--line` 跳到第 N 行并高亮。支持代码、文本、Markdown、CSV、图片、PDF；Office 文件不支持。
- `web`：在右栏“网页预览”里打开网址，只接受 `http://`、`https://`。
- `shot`：在后台加载网址并截图，标准输出只有一行：PNG 的绝对路径。默认存到工作台的 `.run/shots/`（保留 7 天），`--out` 可以给 `.png` 文件或已有文件夹。默认 1280×800，`--size` 改尺寸（宽 320～3840，高 240～4000）。只截首屏，不截整页。最长等 30 秒。

## 什么时候用

- 改完网页、原型、样式后：先 `shot` 截图，用 Read 读这张 PNG 自查，有问题先改再交付。
- 要用户看某个文件的某处（关键改动、报告、配置）：`open <路径> --line N`。
- 开发服务器起来后要用户看页面：`web http://localhost:端口`。

## 注意

- 只作用于发起命令的这个对话：用户正开着这个对话时直接打开；用户在看别的对话时只弹提示，用户点“打开”才显示。所以命令成功不代表用户已经看到。
- 截图需要工作台 App 开着；只在浏览器里打开工作台时会报错，这时告诉用户即可，不要反复重试。
- 截图的是新加载的页面，不是用户右栏里正在看的那一份，需要登录的页面可能截到登录页。
- 不要用它打开和当前任务无关的文件或网址。
